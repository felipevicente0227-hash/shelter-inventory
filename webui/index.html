How it works

  
    
    
  • Inventory is your list: what you have against what you need (the target). Red is urgent, amber is running low, green is fine.
    • 
    
  • Import spreadsheet reads the Excel or CSV list you already keep, so there is nothing to retype. It shows you what it understood before it imports anything.
    • 
    
  • Update stock by typing the new number in the row and pressing Enter. Undo (Ctrl+Z) brings back anything you change by mistake.
    • 
    
  • Use-by dates are optional per item. Expired or soon-to-expire items are flagged in purple.
    • 
    
  • What we need is a ready-made list for donors. Count sheet is a printable list for stock-taking.
    • 
  

  
Where your data lives

  

  
It is a normal folder you can back up by copying it. Nothing is uploaded anywhere, there is no account, and the program never uses the internet.

  
If something goes wrong

  
Press the button below. It opens a new email to the person who made this program, with the version number already filled in. Say what you were doing and what happened, and it gets fixed.
